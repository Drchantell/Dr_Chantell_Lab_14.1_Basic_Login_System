Basic Login System Reflection

In this lab, I learned how to create a basic registration and login system with Express and MongoDB.

I learned how bcrypt hashes passwords before they are saved and how bcrypt compares passwords during login.

I also learned how JWT creates a token after a successful login.

This lab helped me understand the basic steps of user authentication and why private information should be stored in a .env file.
